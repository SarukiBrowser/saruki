# Feedback and contributions

Thank you for trying Saruki! This is an early test build, and reports from real TVs and phones are the most useful
thing you can give the project.

## Very welcome

- **Bug reports:** open an [issue](../../issues/new/choose) with "Bug report".
- **Device reports**, including "it works fine on my TV": "Device report". Every model helps.
- **Ideas and feature requests:** "Feature request", or start a thread in [Discussions](../../discussions).
- **Questions:** [Discussions](../../discussions).

Please include your TV or stick model, the Android TV version, the Android System WebView version
(Saruki → Settings → About Saruki), and for phone problems your phone model and Android version. A photo of the
screen helps a lot.

## Code contributions

**Code contributions aren't accepted for now, so please don't open pull requests.** It isn't personal, and it isn't
about the quality of your code: for the time being the project keeps every line written by one maintainer. If you've
found a fix, describe it in an issue (a short snippet in the issue is fine). It will be written into Saruki with credit
to you in the changelog.

You are of course free to fork Saruki and change it under the GPL-3.0 license.

## Security problems

Please don't post them in public. See [SECURITY.md](SECURITY.md).
